# MRI Analysis for Fear

## Aniha Chalke 19/12/2025

https://neurosynth.org/analyses/terms/fear/

### Project summary

In this project, I have used MRI image data from the link above and visualized it. With the given data, I have visualized the functional data for the concept of fear over an anatomical image of the brain, thus highlighting the areas of activity in the brain. I have also plotted a histogram of the voxel values, showing their distribution.
